CASO 02 — SAÚDE PÚBLICA
Insulogic: distribuição de insulina em posto de saúde
HTML CSS JavaScript MySQL

Sistema desenvolvido em equipe para agilizar o atendimento e a distribuição de insulina em um posto de saúde no Quilometro 11 Tucutí/PA, reduzindo o risco de perder dados de pacientes. CASO 04 — SISTEMAS EMBARCADOS
Robô de navegação com ESP32-CAM
ESP32-CAM Arduino C/C++ YOLOv5 HTML JavaScript

A primeira versao foi desenvolvida com YOLOv5, Responsalvel por Controlar o robo atraves da deteção e a segunda versao. Robô controlado pelo navegador. O ESP32-CAM transmite vídeo ao vivo (MJPEG) e serve a interface web. Um Arduino com motor shield aciona os motores, e um sensor ultrassônico HC-SR04 faz a leitura de distância. Opera em modo manual e em modo automático. Requisito para a Disciplina de Microcontroladores e Microprocessadores com continuidade em Projeto de Hardware e Interfaciamento.

STATUS → protótipo funcional
